# Girki Web

TanStack Start clone of [Girki: Private Chefs Across Africa](https://my-site-98651161.ploy.build/).

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production

```bash
npm run build
npm run preview
```

## Stack

- [TanStack Start](https://tanstack.com/start) + [TanStack Router](https://tanstack.com/router)
- React 19
- Tailwind CSS v4
- Lucide icons
